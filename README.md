# 🔎 Code Archaeologist

Code Archaeologist is a C#/.NET developer tool designed to uncover the hidden architecture and evolution of a software system.

Instead of simply reading source files, Code Archaeologist examines a codebase as a connected system — discovering projects, namespaces, classes, interfaces, methods, dependencies, relationships, architectural patterns, code smells, and eventually how those structures changed throughout the project's Git history.

The goal is simple:

> Don't just read the code. Understand how the codebase came to be.
